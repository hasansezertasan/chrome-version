Installation
============

``chrome-version`` has no runtime dependencies and installs from PyPI.

Stable release
--------------

Install with ``uv``:

.. code-block:: sh

   uv add chrome-version

Or with ``pip``:

.. code-block:: sh

   pip install chrome-version

From source
-----------

The source files for ``chrome-version`` can be downloaded from the
`GitHub repo <https://github.com/hasansezertasan/chrome-version>`_.

Clone the public repository:

.. code-block:: sh

   git clone https://github.com/hasansezertasan/chrome-version.git

Once you have a copy of the source, install it with:

.. code-block:: sh

   cd chrome-version
   uv pip install .
