Public package interface for chrome_version.

chrome_version.get_chrome_version()[source]#

Get the installed Google Chrome version for the current platform.

On Linux and macOS, the function invokes the Chrome binary with the --version flag. On Windows, it first attempts to read the version from the registry; if unavailable, it falls back to parsing the installation directory name.

Returns:

The Chrome version string if detected, otherwise None.

Return type:

str | None

Examples

>>> get_chrome_version()  
'123.0.6312.86'

chrome_version.core.extract_version_folder()[source]#

Extract the Chrome version by inspecting Windows installation folders.

Checks both 32-bit and 64-bit Program Files directories for a Chrome Application folder whose subdirectory name matches a version pattern.

Returns:

The Chrome version string if a matching directory name is found, otherwise None.

Return type:

str | None

chrome_version.core.extract_version_registry(output)[source]#

Extract the Chrome version from a Windows registry query output string.

Parameters:

  • output¶ – Raw text captured from a reg query command targeting the Google Chrome uninstall key.

  • output (str)

Returns:

The Chrome version string (e.g. "123.0.6312.86") if found, otherwise None.

Return type:

str | None

Examples

>>> out = "DisplayVersion    REG_SZ    123.0.6312.86"
>>> extract_version_registry(out)
'123.0.6312.86'
